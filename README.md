# Gene Expression Explorer

🚧 Work in progress — a learning project.

## Goal
Explore a public microarray dataset using Python
and understand the data before comparing samples.

## Dataset
GSE5859Subset from the genomicsclass repository:
https://github.com/genomicsclass/GSE5859Subset

Contains 8,793 probe sets across 24 samples.
Probe sets do not necessarily represent unique genes.

## Progress
- Loaded the dataset using pyreadr.
- Inspected the expression matrix and sample metadata.

## Next steps
- Check sample alignment and missing values.
- Explore sample groups.
- Create visualizations.

## Tools
Python, pandas, pyreadr, Jupyter, VS Code.
